# Learning Computer Science with Open Source Society University
---
[Open Source Society University](https://github.com/ossu/computer-science) is essentially just a well built degree plan for a computer science degree, that uses only free resources built on the internet. 

The way the program is built, it is designed to be taken 1 class after the other, through the entire program. Its divided into a few different sections. 

After the intro and core computer science sections, there is a number of Advanced CS choices. Students are meant to only pick 1 section to complete. and then do so in entirety. 

And Finally, as with all Bachelors degrees, students are to do some form of final project.

I have a [[Vault/OSSU Completion List\|OSSU Completion List]] to track classes and completion since its a linear project.
